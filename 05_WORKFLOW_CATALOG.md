# Workflow Catalog

| Workflow | Purpose |
|---|---|
| bootstrap | Initialize a new project from product requirements |
| feature | Deliver a vertical slice |
| bugfix | Reproduce, isolate and minimally fix a defect |
| refactor | Improve structure while preserving behavior |
| migration | Safely change schema/data |
| ui-refinement | Improve functional UI to high-fidelity |
| release | Verify and approve a release |

Each workflow must define trigger, objective, states, actors, inputs, outputs, transitions, retries, timeout, fallback, approvals, artifacts and terminal states.
