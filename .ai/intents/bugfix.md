# Intent: Fix Bug

Trigger examples:
- Fix bug: ...
- Repair bug: ...

## Execute

1. Create a bugfix task.
2. Reproduce the defect before changing code where practical.
3. Identify root cause.
4. Implement the smallest justified fix.
5. Add/update regression coverage.
6. Run the bugfix graph and applicable quality/security gates.
7. Collect evidence.
