# Gate Catalog

## G1 Requirement Gate
Checks user story, acceptance criteria, permissions, business rules and blocking ambiguity.

## G2 Architecture Gate
Checks module ownership, dependency direction, public contracts, data ownership and unnecessary abstractions.

## G3 Database Gate
Checks schema, migration safety, indexes, constraints, backward compatibility and rollback strategy.

## G4 Contract Gate
Checks request/response schemas, errors, permissions and contract compatibility.

## G5 Code Quality Gate
Checks lint, formatting, types, duplication, complexity and scope.

## G6 Test Gate
Checks unit, integration, contract, regression and permission coverage as applicable.

## G7 Security Gate
Checks secrets, unsafe inputs, access control, dependencies and prohibited operations.

## G8 UI Gate
Checks design-system compliance, required states, responsive behavior and accessibility.

## G9 Release Gate
Checks evidence completeness, build integrity, migration readiness and approvals.
